## The joke

> My cat knocked my water glass off the nightstand at 3 a.m., then glared at me like I'd interrupted her meeting with the wall.

## Run

```sh
python3 main.py
```

Writes the single joke line to `/output/entry.txt` (override with the `ENTRY_OUTPUT_DIR` environment variable). Stdlib only, no network, deterministic.
